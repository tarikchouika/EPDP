## الخيار 1 — دفع بنفسك عبر الحزمة الجاهزة (بدون أي توكن)

1. حمّل الملف `EPDP-commits-b94e505.bundle` من هذه الصفحة.
2. في نسختك المحلية من المستودع (على جهازك):

```bash
cd EPDP                      # نسختك المحلية من github.com/tarikchouika/EPDP
git fetch /المسار/إلى/EPDP-commits-b94e505.bundle main
git merge FETCH_HEAD          # fast-forward نظيف — لا تعارض
git push origin main
```

3. بعد الدفع يعمل GitHub Actions تلقائياً (`branches: [main]` سليمة) وينشر عبر Cloudflare Pages خلال 2-3 دقائق.

## الخيار 2 — توكن مؤقت يقوم بالدفع هنا

أنشئ توكن GitHub مؤقتاً بصلاحية **Contents: Read and write** على مستودع EPDP فقط
(Settings → Developer settings → Fine-grained tokens)، أرسله هنا، وسأنفّذ:

```bash
git push https://x-access-token:<TOKEN>@github.com/tarikchouika/EPDP.git main
```

ثم تحقّف من ظهور النسخة الجديدة على epdp.pages.dev قبل إبلاغك. **احذف التوكن فوراً بعد ذلك** من GitHub.
